# Migration from v0.2

v0.3 replaces pre-release profile-only commands and Luau extensions with Theme
Bundles and fixed built-ins. Both repository hosts are migrated together; no
long-lived compatibility API is retained.

## Configuration

- Replace `[provider]` with named `[color_providers.<name>]` and
  `[color_palettes.<name>]`.
- Replace `default_profile` with `default_theme` and declare
  `[theme_bundles.<name>]`.
- Replace `[targets.<name>]` with typed `[application_wires.<name>]`.
- Remove `extensions`, adapter IDs such as `luau:foot`, and configurable output
  paths. Outputs now live beneath `generated_dir`.
- Add Application Contracts and, when declarative appearance assets are used,
  an `appearance_inventory_file` generated by Nix.
- Rebuild-owned bundle selections must use `{ library, item }`. The repository
  hosts select `stylix-cursors/bibata-modern-ice`; Nix reads that same bundle
  reference, configures upstream Stylix, and emits its effective inventory.

## Commands

- `list` becomes `theme list`.
- `apply <profile>` becomes `apply <theme>`.
- `components`, `plugins`, `doctor`, `resolve`, and `tui` are removed.
- Use `check`, `status`, and their JSON reports for validation and diagnostics.

## State and files

The next apply reads a v0.2 `active_profile` as the active bundle name and then
rewrites state in the minimal v0.3 format. Generated Niri and Foot bytes remain
compatible. Old ownership hashes, disabled-target state, and transaction
journals are intentionally discarded because v0.3 owns one exclusive generated
directory and has no runtime component toggles.
