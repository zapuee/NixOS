# Theme Manager

Pure-Luau Noctalia plugin for switching Noctalia profiles and applying live structure profiles.

## Layout

- `panel.luau` — profile picker UI only.
- `watcher.luau` — watches the active structure profile and drives the incremental pipeline.
- `lib/` — shared paths, profile discovery, persistence, and profile actions.
- `structure/parser.luau` — incremental parser for the structure-profile TOML subset.
- `structure/resolver.luau` — shared selector/validation logic.
- `structure/pipeline.luau` — incremental apply state machine; one bounded stage per service tick.
- `structure/generators/` — target-specific generators for Niri and Foot.

## Live-update design

The watcher reads the active structure profile asynchronously. When contents change, the apply pipeline parses a bounded number of lines per update tick and then runs each generator/write stage separately. This avoids Noctalia's per-callback Luau CPU budget while keeping everything in Luau.

Generated files live in `~/.config/theme-manager/`:

- `niri.kdl`
- `niri-colors.template.kdl`
- `niri-colors.kdl` (rendered by Noctalia)
- `foot.ini`

The active structure profile name is persisted with `noctalia.pluginDataDir()` so it survives Noctalia/plugin reloads.

## Current structure-profile backends

Implemented:

- Niri gaps / outer gaps
- Niri focus-ring width and wallpaper-derived colors with separate active/inactive/urgent alpha
- Niri shadow enable/color alpha
- Niri global and app-specific corner radius
- Niri compositor blur for Foot and Firefox
- Foot dark/light background alpha

Present in the profile schema but not yet generated by a backend:

- Firefox `background_opacity`
- Firefox `accent_color`
- terminal `gaps`
- terminal `cursor_color`
- terminal `selection_color`
